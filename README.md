# VoipTupniquim

Projeto reorganizado em frontend e backend separados.

## Estrutura

- `frontend/` - Aplicação React com Vite e TypeScript.
- `backend/` - API Node.js com Express e TypeScript.

## Comandos

No diretório raiz:

```sh
npm install
npm run dev:frontend
npm run dev:backend
```

Ou para rodar ambos em paralelo:

```sh
npm run dev
```

## Endpoints

- Frontend: http://localhost:5173
- Backend: http://localhost:4000
- API health: http://localhost:4000/api/health
